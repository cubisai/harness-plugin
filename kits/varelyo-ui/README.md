This is an unofficial kit that follows the Varelyo Foundation look, component set and prop names. It is not affiliated with or endorsed by Varelyo, and every file here is written from scratch with no source copied.

The library is MIT-licensed open source, and its source is meant to be copied into a project, so there is no npm package to import. `components.json` gives each part's name, props and snippet, and the library's component folder names are listed in its docs, so a page can be mapped part by part to the source. The kit loads nothing and has no build step.

The fonts are the system UI stack that the library uses, so no font files are bundled.

Themes: `neutral` and `slate` are the library's two brands. The five accent themes are not from the library; they are colour overrides made for this kit.
